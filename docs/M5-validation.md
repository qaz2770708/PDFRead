# M5 数据、保存与恢复验收

运行 `./test.ps1 -NoRestore`，包含八组 Windows 验收：原阅读/目录/书签、存储恢复、多窗口交互、集中进度、注释、页内编辑，以及新增 PersistenceAcceptance 和 PersistenceUiAcceptance。

## 持久化故障验收

- `报告.pdf` 与哈希目录内 `报告.pdfdata` 配对；相同内容改名不重复生成。
- 保存并重新加载书签层级、注释、便签正文/副文本、颜色、阅读页码和缩放。
- 导出同名数据，复制 PDF 及数据到独立位置，并换用另一套 data 根目录模拟另一台电脑，验证加载和源文件保留。
- 内容变化的四项决策：新建、沿用、临时不加载、取消；各项决策在提交前均不覆盖旧文件。
- 使用实际独占/共享文件锁制造保存失败，核对内存修改、修订号和旧正式文件不变，同时留下完整临时恢复快照。
- 从更高修订号的有效临时快照恢复；有效备份恢复；合法 JSON 的正文被改动后由完整性校验识别；损坏原件及有效候选在恢复前归档。
- 两份过期会话及保存锁验证并发写保护；新格式拒绝打开，避免以旧备份覆盖未来格式。
- v5 升级前已有原始字节备份，保存后备份仍在；未知注释类型导致升级失败，以及备份目录不可创建时，源文件均未覆盖。
- 另存并切换后重开使用新位置；数据另存不能覆盖原 PDF；所有测试前后原 PDF SHA-256 相同。

## 实际窗体验收

- 页面创建、输入、修改便签正文与副文本，未提交输入即时显示“未保存”，Ctrl+S 显示“已保存”。
- 关闭后重开核对书签、文本批注、便签和页内位置/缩放。
- 保存失败提示、失败后保留修改、暂停重复弹窗、关闭拦截、解除锁定后重试、失败时另存并切换位置。
- 损坏数据导入失败不改变现有会话。实际四选项版本提示和保存失败对话框参与控件点击，并检查截图布局。
- 原八图标、快捷样式、F2 属性以及所有既有回归继续验证。便签增加独立图标与 Ctrl+Shift+N，不改变八个注释图标布局。

验证方式为真实 WinForms 消息循环、原生控件与文件锁，布局使用 DrawToBitmap 截图检查；未声明桌面物理鼠标人工验收，也未声明在第二台实体电脑测试。跨电脑读取以不同 data 根目录及复制文件模拟。

发行要求：Release 零警告零错误；ZIP 独立解压后验证渲染、目录、缩略图、文字提取、文本和便签持久化，检查包内无个人数据、凭据和 scratch 文件。详细行为与延迟保存边界见 data-storage.md。
