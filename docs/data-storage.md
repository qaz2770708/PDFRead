# 集中数据与进度恢复

新版只在 EXE 所在目录的 data 文件夹写入数据。相同内容的 PDF 通过 SHA-256 识别，固定使用 data/<sha256>.pdfdata；重复打开或重命名不会新建另一份数据。index.json 记录路径与最近哈希，用于识别原路径内容变化，文件保存采用固定 .tmp 和 .bak 原子替换及恢复规则。

打开时先读取已有哈希数据，然后恢复页码、页内纵横位置和缩放。恢复及初次布局期间暂停位置写入，避免第一页覆盖已保存进度。阅读进度延迟 800ms 保存，关闭时立即保存。未修改数据的重开不增加版本或重写数据。

当集中数据不存在时，检测旧版 PDF 旁的 .pdfdata、.tmp、.bak，读取后保存到集中目录，旧文件保留且不再写回。原路径 PDF 内容改变时询问新建当前版本或确认沿用旧记录；旧哈希文件保留。复制到另一台电脑时应复制整个 data 目录与 PDF；只复制 PDF 本身不能带走独立注释。软件目录必须可写，失败会明确提示，不会回退到 PDF 所在目录生成文件。

格式升级为 v4，保留 v1/v2/v3 进度、书签、注释与旧版本记录。新路径且内容也改变的文件无法仅凭哈希确定它是否来自旧文件，作为新文档保存。应用内相同哈希只保留一个可写会话，避免同一数据被两个标签覆盖。
