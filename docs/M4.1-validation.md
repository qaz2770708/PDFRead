# M4.1 图标与页内批注验收

本次将注释工具下拉菜单替换为 8 个可见图标，保留原快捷键和 F2 专业属性。快捷样式仅提供 6 种预设颜色，专业属性仍允许任意颜色和所在页设置。

验证运行于 Windows 的实际 WinForms 消息循环，通过控件事件、输入内容及窗口生命周期验证；并检查 DrawToBitmap 生成的整窗、图标栏和快捷面板截图。未将桌面物理鼠标操作声明为人工验收。

## 验证范围

- 8 个工具使用图标按钮，无工具下拉菜单，悬停元数据包含名称及快捷键；矩形和椭圆独立，文本图标使用 SimSun A。默认及最小窗口下图标均未裁切，右栏继续占阅读区高度 80%。
- 页面点击创建获得焦点的文本框，不弹模态属性窗，不保存空框；中文、多行输入、400ms 延迟保存与 Ctrl+S 提交均正常。
- 6 色圆点改变文本颜色并显示十六进制色号，快捷面板无自定义颜色输入；字号、透明度支持滑条及两端加减，透明度可到 100%。
- 拖动标题移动及拖动角部调整大小；保存归一化页面坐标。滚动、缩放时输入框跟随批注，焦点回到输入框不改变阅读位置。
- 文本输入时 Delete 和 Ctrl+Z 不触发整条注释删除或注释历史。Ctrl+Enter 结束，Esc 丢弃尚未提交修改，清空文本删除已有批注，空草稿取消后不落盘。
- 切换标签、关闭窗口、拖出独立窗口会提交尚未触发延迟保存的输入。关闭后重开恢复文字、字体、颜色、字号、透明度及位置。
- F2 仍调用专业属性，修改所在页会跳转至相应页面；实际模态弹窗的打开和取消由原注释验收覆盖。
- 原 PDF 哈希不变。所有阅读、数据恢复、多标签/窗口、目录/书签、七类注释回归套件继续通过。

运行 `./test.ps1 -NoRestore` 执行六组验收；新套件为 tests/InlineEditorAcceptance.cs。Release 要求零警告零错误，发行包解压后独立验证渲染、目录、缩略图、文字位置提取、图标工具、页内文字保存及根目录 data 配对。

## 边界

原生输入框聚焦时显示可读的编辑文字，透明度在输入焦点离开后由注释层预览；不改变保存的透明度。新批注默认宋体，旧批注保留字体外观，数据升级规则见 data-storage.md。撤销历史仍最多 30 步且仅在当前会话内保留。
