# M4 注释与阅读基础验收

## 已验证

Windows 下运行 ./test.ps1（已有依赖可加 -NoRestore），包含原阅读/目录/书签、数据恢复、多窗口、集中数据与进度、注释编辑五组验收。

进度验收使用旧版 v3 样例导入：在真实窗体首次布局后仍保持旧页码、页内位置和缩放；关闭重开恢复最新位置；无改动重开不重写数据，同一内容仅有一份固定哈希数据。复制或重命名复用记录，原路径内容修改会询问，并保留旧哈希文件。根目录 data、自动导入和 v4 升级规则见 data-storage.md。

工具栏验证覆盖高度 80%、上下各 10% 和八组控件间隔一致。目录恢复为原生纯文字树，页面缩略图标签保持不变。已检查工具栏截图及实际注释属性对话框截图。

注释验收对高亮、下划线、文本、手写、矩形、椭圆、直线逐类执行：快捷键选工具、鼠标新增、命中选择、属性编辑、移动、四角缩放、删除、撤销、重做，再关闭窗口并重新打开核对所有标注。另验证跨页属性修改、取消文本输入、取消拖动、拖动过程中自动保存不写入未提交的预览、源 PDF 哈希不变，以及字形位置和笔迹点列的持久化。

文字高亮/下划线使用文本解析器的页面字形四边形，按文字行合并后保存；旋转和裁剪页参与坐标测试。原 PDF 渲染层仍由 Windows PDF API 负责，注释层单独绘制和维护编辑历史。Release 构建无警告、无错误，发行包独立解压后检查所有运行依赖、目录、阅读渲染和注释文字区域提取。

## 操作边界

- 注释坐标是归一化页面坐标，文本区域、笔迹点列随移动/缩放一同变换，不记录屏幕像素。拖动限定在当前页，跨页可通过属性的“所在页”设置。
- 文本高亮/下划线以拖框选到的文字为范围；无文本的扫描页或解析失败时按区域标注，不执行 OCR。自定义复杂字形/文字排版的边界可能依赖 PDF 字体质量。
- 文本批注可编辑文本；其他类型同样可附加批注文字并编辑颜色、不透明度、线宽。文本字号通过属性修改。形状为轮廓绘制，手写可修改颜色/线宽、整体移动或缩放，不提供逐个笔迹点擦除。
- Delete/F2 针对阅读区所选注释，书签树的删除/改名与输入框编辑不会被抢占。注释工具切换使用 Ctrl+Shift 快捷键，见 shortcuts.md。
- 注释撤销/重做最多保留 30 步，仅保存在当前会话，重开后历史清空；注释本身、阅读进度和书签长期保存。拖出窗口保留现有注释层和历史，重新绑定保存事件。
- 保存失败保留内存修改并提示，原 PDF 从未写入；数据目录无写权限时不会转而在 PDF 旁创建文件。旧版源数据导入后保留，避免升级丢失原数据。
- 程序尚不向 PDF 内写入注释，也不提供导出带注释 PDF。要跨电脑带走阅读状态和标注，复制 data 及 PDF。

验收使用实际 WinForms 消息循环、控件事件和原生鼠标释放消息分支。桌面截图接口此前不稳定，因此不将真实桌面物理鼠标操作声明为已完成人工验收。
