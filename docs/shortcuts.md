# 阅读快捷键

| 操作 | 快捷键 |
| --- | --- |
| 打开 / 保存 / 关闭标签 | Ctrl+O / Ctrl+S / Ctrl+W |
| 下一个 / 上一个标签 | Ctrl+Tab / Ctrl+Shift+Tab |
| 放大 / 缩小 | Ctrl+滚轮，Ctrl++ / Ctrl+-（含数字小键盘） |
| 100% / 适合整页 / 适合宽度 | Ctrl+0 / Ctrl+1 / Ctrl+2 |
| 页码输入框 | Ctrl+G，输入 PDF 实际页码后 Enter |
| 上一页 / 下一页 | Ctrl+PageUp / Ctrl+PageDown |
| 第一页 / 最后一页 | Ctrl+Home / Ctrl+End |
| 开关区域高亮 / 返回阅读 | Ctrl+Shift+H / Esc |
| 快捷键帮助 | F1 |

Ctrl+滚轮每个标准刻度改变 10 个百分点，范围为 35%～220%。鼠标在页面内时保持指向的页面坐标；高精度滚轮累积不足一个刻度的增量。文档边缘因滚动范围限制可能无法保持锚点。普通滚轮继续滚动并同步页码。缩放和阅读位置沿用延迟自动保存。

验收：通过 WinForms 消息循环程序验证快捷键分发、100%/加减缩放、鼠标锚点误差、高精度滚轮、上下限、首末页、高亮退出，以及普通滚轮与滚动条页码同步和可见页渲染。Release 构建通过。

Ctrl+D 添加当前位置为用户书签；Ctrl+B 显示/隐藏导航栏。书签树中 F2 重命名、Delete 删除所选及子级、Enter 跳转。书签顶部仅保留添加、删除。右键书签可添加子书签、改名、删除及更新为当前阅读位置；右键空白处可添加根级书签。

右侧悬浮工具中的目录/缩略图/书签按钮可展开对应导航，再点击同一按钮可收起。标签右侧 × 或双击标签关闭；按住拖动左右排序，移到当前窗口外部松开创建独立窗口，Esc 取消拖动。

## 注释快捷键（M4）

| 操作 | 快捷键 |
| --- | --- |
| 选择 / 移动 | Ctrl+Shift+A |
| 高亮 / 下划线 | Ctrl+Shift+H / Ctrl+Shift+U |
| 文本批注 / 手写 | Ctrl+Shift+T / Ctrl+Shift+P |
| 矩形 / 椭圆 / 直线 | Ctrl+Shift+R / Ctrl+Shift+E / Ctrl+Shift+L |
| 所选注释属性 / 删除 | F2 / Delete |
| 注释撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 取消未提交操作 / 清除选择 | Esc |

所有工具也可点击右侧对应图标，悬停显示名称和快捷键。矩形、椭圆分别提供独立按钮。选择工具点击已有批注显示页内样式面板，双击也可打开。形状拖动四角缩放，文本框拖动上方标题移动、拖动右下角调整大小。

选择宋体 A 图标（Ctrl+Shift+T）后，在页面点击即可输入文本。颜色圆点直接设置文字颜色并显示色号；字号、透明度使用滑条或两侧加减按钮。0% 透明度完全可见，100% 完全透明；文本正在输入时以原生输入控件显示，焦点离开输入框后可见透明度预览。

文本改动停止 400ms 后自动保存。Ctrl+S 立即保存，Ctrl+Enter、完成按钮或点击页面空白处结束编辑；切换工具、标签页、关闭或拖出窗口同样提交待保存输入。Esc 放弃尚未提交的修改；已经自动保存的内容可结束编辑后 Ctrl+Z 撤销。清空文本会删除该批注，未输入的空框不保存。

输入框内 Delete 和 Ctrl+Z 交给文本编辑；阅读区 Delete 删除整条批注。F2 始终打开专业属性弹窗，可设置任意颜色、所在页及更精确的数值。右键菜单提供快速样式、专业属性、删除、撤销和重做。

## 数据与便签（M5）

Ctrl+Shift+N 选择页面便签工具，再点击页面创建；正文直接输入，快捷面板可编辑副文本，移动标题和右下角调整大小。Ctrl+Shift+S 另存并切换数据文件，Ctrl+S 保存或重试。右栏“数据”菜单还提供导出同名数据、手动加载数据文件。便签与文本批注一样自动保存，支持删除及注释撤销/重做。

## 书签拖放与 PDF 导出（M6）

拖动书签到另一行的上/下边缘可调整同级顺序；拖到行中间可归入该书签，拖到空白处可移到根级末尾。拖动父书签会保留其整个子树，蓝线表示插入位置，虚线框表示归入子级；悬停展开节点，靠近上下边缘自动滚动。不能拖到自己、自己的后代或另一份 PDF 的书签栏。

右键只选择书签，不跳转页面。叶子书签直接删除；包含子书签时先确认，删除会作用于整个子树。F2、Delete、Enter 分别保持改名、删除和跳转。

Ctrl+E 或“数据 → 导出带注释的 PDF”选择新文件位置；已有目标需确认覆盖，不能选择原 PDF。导出前会提交当前输入并保存数据；源文件或数据被外部修改时，需重新打开或加载后再导出。导出合并注释与便签外观，原 PDF 内已有目录、链接及可搜索文字保留；用户书签继续保存在 .pdfdata 中。

## HeroUI 界面

快捷键沿用原规则，右侧图标悬停有名称和快捷键。数据菜单位于下载图标。Ctrl+滚轮支持小增量累积；批注输入过程中缩放会保留编辑框。窗口标题栏可拖动，双击空白标题栏切换最大化；标签拖动排序，拖到窗口外松开建立独立窗口，Esc 取消标签拖动。

原文选择：默认选择工具下拖选或双击选词，三击选段；Ctrl+C 复制所选文字，Ctrl+A 选择当前 PDF 页文字。右键可复制、选段、选本页或取消选区；编辑输入框内仍按输入框规则处理。无法提取原文时自动启动本机 Windows OCR，识别完成即可选字；识别失败可点击重试。
