# 右侧工具、页面预览与多窗口验收

## 操作规则

- 顶部仅保留打开 PDF，每个标签右侧 X 关闭对应文档，双击标签关闭。关闭前按现有规则保存，保存失败保留标签和内存数据。
- 按住标签拖动超过系统拖动阈值后可左右排序；拖到当前窗口边界之外松开才创建新窗口，在窗口内部的阅读区松开不创建窗口。Esc 取消拖动。
- 拖出转移现有文档会话及页内位置、缩放、书签、标注、缩略图缓存，不重新打开文档，不创建第二份可写会话。多个窗口各有自己的右侧工具和导航。关闭原窗口后，其他窗口继续运行；最后一个窗口关闭才退出应用。
- 同一应用内重复打开相同路径会激活已有窗口。同一 PDF 被其他独立程序进程同时打开的并发写入控制不在本次更新范围。
- 右侧浮层只影响工具本身的透明度：默认透明度 60%（Opacity 0.40），悬停或编辑页码时为不透明。目录/缩略图/书签按钮可展开或收起右侧导航；Ctrl+B 也可切换。
- 目录条目显示其目标页缩略图；缩略图标签列出所有页。点击预览后阅读区和页码框同步。侧栏关闭时停止预览加载，按可见范围每次生成一页，缓存上限 40 页，切换文档不会串用缩略图。预览失败显示明确占位提示，不阻塞主阅读区。

## 自动验收

`./test.ps1` 依次执行阅读/目录/书签验收、数据恢复回归及 `UiInteractionAcceptance`。已有依赖时使用 `-NoRestore`。均使用工作区内样例副本。

界面验收在实际 WinForms 消息循环中运行：验证顶部只有打开按钮、工具实际位于右侧浮层、页码控件不换行、保存状态完整可见、导航开关、目录目标预览、真实缩略图像素、点击缩略图的页码同步。

标签验收覆盖 X 关闭前保存、双击关闭、拖动排序、原生 WM_LBUTTONDBLCLK/WM_LBUTTONUP 分支、拖出新窗口、原会话及缓存转移、阅读位置/缩放恢复、未保存书签保留、事件重新绑定后仅创建一次标注、独立保存，以及关闭原窗口后的后续计时器仍能运行并渲染。

Release 构建与三组验收通过。已查看实际窗体及浮层控件截图。桌面截图接口在本机连续出现 `FrameArrived timed out` / `window capture timed out`，因此未把原生桌面上的物理鼠标拖动标记为人工验收完成；以上鼠标交互由窗体事件和原生消息分支自动验收。
