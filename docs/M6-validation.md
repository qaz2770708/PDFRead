# M6 用户书签交互与带注释 PDF 导出验收

运行 `./test.ps1 -NoRestore` 执行十一组 Windows 验收。本次增加 BookmarkAcceptance、PdfExportAcceptance、PdfExportUiAcceptance，既有八组阅读、目录、数据、恢复、多窗口和注释验收继续保留。

## 书签

顶部只保留添加、删除。原上下、左右、子级、改名和更新按钮已移除；右键菜单承接添加子级、改名、删除和更新位置，空白处提供添加根级书签。右键不跳页，拖动后不触发意外导航。

验证真实控件事件中的拖放数据分发：上边缘前插、下边缘后插、中间归入子级、空白处移到根级。父节点移动保留全部后代；自己、后代和其他文档的拖放被拒绝。拖放有插入线或归入虚线框，悬停展开及边缘滚动，刷新保留折叠状态。

核对右键选中、子级添加、原生文字改名、空白添加、叶子删除、子树删除确认和取消、更新阅读位置，并关闭重开校验顺序、层级和名称持久化。书签只改变数据文件，原 PDF 哈希不变。

## 导出

Ctrl+E 或数据菜单选择新的 PDF 文件名和目录；目标存在时确认覆盖。导出前提交页内输入和保存数据，按 PDF SHA-256 从 .pdfdata 读取对应版本。原 PDF 或数据外部改动时拒绝使用过期会话导出。

使用 PDFsharp 修改内存中的源文档副本，原始页面内容保持 PDF 内容；独立注释层以透明外观合入新文件。外观绘制复用阅读器绘制逻辑，不包含选择框、缩放手柄或编辑面板。普通页面注释层按 288dpi 输出，大页面按 1600 万像素/单边 12000 像素上限调整分辨率；原 PDF 内容不会整体转成图片。

写入同目录的唯一临时 PDF，重新打开核对页数后再原子提交。覆盖前核对目标未在导出期间改变。失败清理临时产物，保留原目标；禁止覆盖原 PDF，包括同文件身份的硬链接别名。原 PDF 和 .pdfdata 的导出前后指纹相同。

八页几何测试涵盖 0/90/180/270 度、裁剪、非零媒体原点、UserUnit。逐页核对所有八类标注（高亮、下划线、文本、手写、矩形、椭圆、直线、便签）的像素外观，包含中文、多行、副文本、颜色和透明度。对照图为源页面加阅读器注释外观，导出渲染采用 Windows PDF API；另用 Poppler 独立渲染抽检正常页及旋转页，检查中文无缺字、背景透明、形状与文字位置正确。

实际窗体入口验证 Ctrl+E、未等待自动保存的输入提交、取消选址、目标覆盖确认/拒绝、禁止原文件路径，以及外部数据改动时停止。导出后用解析器验证原 PDF 目录、页内链接和可搜索文字仍可用。

## 边界与发行

导出将批注外观合成到 PDF；后续编辑仍使用原 PDF 和 .pdfdata。当前不把用户书签转换成 PDF 内嵌目录，不执行 OCR。加密或 PDF 解析器不支持的源文档会明确报错，不回退成整页截图。较大文档导出期间显示“导出中”。

验证使用 WinForms 消息循环、原生控件事件、真实文件锁、硬链接以及独立 PDF 渲染；未将桌面物理鼠标拖放宣称为已完成人工验收。发行要求 Release 零警告零错误，ZIP 独立解压后复查渲染、图标、便签、数据配对、书签控件与导出，并检查无个人数据或凭据。annotated-demo.pdf 是由 navigation.pdf 导出的样例，保留目录与原页面链接。
