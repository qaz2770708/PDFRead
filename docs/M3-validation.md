# 快捷操作与第三步验收

先完成快捷操作和滚动回归，通过后开发书签与目录。源码测试在 tests/，Windows 下执行 ./test.ps1；已有依赖时可用 ./test.ps1 -NoRestore。测试建立独立的 work/acceptance-* 和 work/storage-* 样例副本，不修改用户 PDF。

## 快捷操作

验证键盘分发、主键盘与数字键盘缩放、100%、适合整页/宽度、首末页、多标签前后切换、高亮开关和 Esc 取消未完成框选。Ctrl+滚轮使用与真实鼠标消息共用的处理函数模拟 Ctrl 状态，验证鼠标锚点、60+60 高精度增量、上下限及消费滚动消息。普通滚轮和滚动条均验证页码同步。测试在实际 WinForms 消息循环中运行，不等同于人工操作物理鼠标。

## PDF 目录与书签

- samples/navigation.pdf 是四页合成样例，包含两级目录、XYZ 目标、间接数组、旧式命名目标、名称树中的 GoTo、旋转裁剪页、无文档内目标条目，以及第一页跳至第四页的内部链接。
- 点击目录节点后，实际阅读页及页码输入框与目标一致。PDF 内部目标页对象用于定位，显示 PDF 实际页码，不通过章节文本中的数字猜测页码。
- 用户书签验证添加、父子层级、重命名、更新目标、升降级、同级排序、子树删除、重新打开恢复、页内位置/缩放恢复、多 PDF 隔离、PDF 与数据副本复制配对。
- 验证 v1/v2 到 v3 格式升级、临时文件恢复、备份恢复、较新恢复候选选择、哈希版本识别、标注与阅读进度持久化、连续页布局及原 PDF 哈希不变。
- 构建零警告、零错误；实际窗体截图检查导航栏和渲染。

## 范围

没有内嵌目录和内部链接的纯文本/扫描目录不自动识别，可使用用户书签。外部网址、外部文件和无效目录目标不跳转到伪造页码；无效目标显示为灰色。目录解析错误显示提示，阅读层继续工作。XYZ、Fit/FitB、FitH/FitBH、FitV/FitBV、FitR 支持目标页与可用位置；特殊视图适配和超出 35%～220% 的 PDF 缩放会按阅读器支持范围处理。当前不提供页标签（如罗马数字）与实际页序之间的自动映射。

数据格式为 v3。保留旧版本 PDF 记录；升级过程中使用现有原子保存和最近备份规则。v1/v2 阅读器不能读取 v3，重新打开请使用新版。

发行包单独解压后，由不携带 PDFsharp 依赖的隔离启动探针加载包内 PDFReader.exe，验证内嵌目录加载和首屏渲染均成功；ZIP 完整性检查通过，未包含 .pdfdata，包内 EXE 与 outputs/PDFReader.exe 完全一致。
