# PDF 阅读器 M3.1

解压 PDFReader-M3.1.zip 后运行 PDFReader.exe。请保留同目录所有 DLL 和配置文件。需要 Windows 10/11 与 .NET Framework 4.8。

按住 Ctrl 滚轮缩放；Ctrl+O 打开 PDF，Ctrl+S 保存，Ctrl+Tab 切换标签，Ctrl+G 输入 PDF 页码，F1 查看完整快捷键。

顶部只有“打开 PDF”。右侧悬浮工具提供目录、缩略图、书签、页码、缩放、高亮、保存和状态；默认透明度 60%，鼠标移入或输入页码时变清晰。

点击右侧“目录”“缩略图”“书签”展开相应导航，再点同一按钮或“收起 ×”隐藏。目录章节显示目标页面预览，缩略图列表显示所有页面；点击即可跳到实际 PDF 页码。缩略图仅按可见范围渐进加载，最多缓存 40 页。navigation.pdf 是带目录及链接的四页测试样例。

每个 PDF 标签右侧 X 关闭该文档，双击标签也可关闭。按住标签左右拖动排序；拖到当前窗口外部松开后创建新窗口，保留阅读位置、缩放、书签和标注。关闭原窗口后，新窗口继续使用。应用内再次打开同一路径 PDF 会激活已有窗口，避免同时写同一份数据。

Ctrl+D 创建用户书签；可添加子级、重命名、更新阅读位置、调整顺序/层级、删除。单击书签恢复页码、页内位置和缩放；Ctrl+B 收起导航栏。

原 PDF 不修改，数据保存于同名 .pdfdata，可与 PDF 一起复制。v1/v2 数据自动升级到 v3；旧版本阅读器不支持 v3，请使用本版本打开。

没有内嵌目录或链接的纯文本/扫描目录暂不自动识别，可创建用户书签。目录解析失败会显示提示，不影响阅读。当前仍只有区域高亮；其他注释、便签和导出待后续开发。
