# PDF 阅读器（第三步）

解压 PDFReader-M3.zip 后运行 PDFReader.exe。请保留同目录所有 DLL 和配置文件。需要 Windows 10/11 与 .NET Framework 4.8。

按住 Ctrl 滚轮缩放；Ctrl+O 打开 PDF，Ctrl+S 保存，Ctrl+Tab 切换标签，Ctrl+G 输入 PDF 页码，F1 查看完整快捷键。

左侧 PDF 目录按原文档层级显示，点击章节跳到标注的 PDF 实际页码。文档页面上已有的内部目录链接也可直接点击。navigation.pdf 是带目录及链接的四页测试样例。

Ctrl+D 创建用户书签；可添加子级、重命名、更新阅读位置、调整顺序/层级、删除。单击书签恢复页码、页内位置和缩放；Ctrl+B 收起导航栏。

原 PDF 不修改，数据保存于同名 .pdfdata，可与 PDF 一起复制。v1/v2 数据自动升级到 v3；旧版本阅读器不支持 v3，请使用本版本打开。

没有内嵌目录或链接的纯文本/扫描目录暂不自动识别，可创建用户书签。目录解析失败会显示提示，不影响阅读。当前仍只有区域高亮；其他注释、便签、跨窗口拖动标签和导出待后续开发。
