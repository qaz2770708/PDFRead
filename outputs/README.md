# PDFReader M6

关闭旧版后解压运行 PDFReader.exe，保留全部 DLL、配置及原有 data 目录。需要 Windows 10/11 和 .NET Framework 4.8，软件目录应可写。

## 数据与迁移

`报告.pdf` 默认配对 `data/<SHA-256>/报告.pdfdata`。相同 PDF 重开恢复阅读位置、缩放、书签、注释和便签，同名不同内容由哈希目录区分。

迁移电脑可复制整个 data 目录及 PDF；也可通过右栏“数据 → 导出随 PDF 的同名数据”生成 `报告.pdfdata`，与 PDF 放在同一目录并一起复制。新电脑打开 PDF 后自动导入。导出副本不会随之后的阅读自动更新，需要交付前重新导出。

“数据”菜单提供重试、另存并切换、导出及手动加载。Ctrl+S 保存或重试，Ctrl+Shift+S 另存并切换；导入另一份有效数据前会确认替换。

PDF 内容变化时选择新建记录、沿用旧注释、不加载数据或取消。选择不加载时本次不自动保存；有新批注需要显式另存。旧版本始终保留。

保存失败保留内存修改，可重试或另存，未解决时不能关闭以免丢失修改。完整临时快照与有效备份可询问恢复，损坏数据不自动清空覆盖。旧格式升级前先备份，v6 数据请用本版打开。保护与升级备份位于 data/_backups。

## 阅读与注释

右侧工具占阅读区高度 80%，默认透明度 60%，导航可开关。目录为纯文字，缩略图单独显示。标签支持 X/双击关闭、拖动排序和拖出独立窗口。

8 个注释工具以图标显示并提供悬停说明。宋体 A 点击页面直接输入文本，拖动标题移动、拖动右下角调整大小。快捷样式提供 6 色圆点、色号、字号/线宽和透明度滑条及加减；F2 保留专业属性。Ctrl+Enter 完成，Esc 放弃尚未保存编辑，清空正文删除文本批注。

便签按钮或 Ctrl+Shift+N 后点击页面创建便签，支持正文、副文本、颜色、位置、大小和删除；注释历史支持最多 30 步撤销/重做。正文和副文本均为空时不会保存空便签。

F1 查看快捷键；高亮/下划线优先使用文字位置，扫描页无可提取文本时按区域标注。便签和注释均属于独立层，原 PDF 不修改。OCR 尚未实现。

## 用户书签与 PDF 导出

用户书签栏顶部仅保留添加、删除。拖到行的上下边缘排序，中间归入子级，空白处移到根级；拖动父书签会带上子书签。右键书签可添加子级、重命名、删除、更新当前位置；右键空白处直接添加根级书签。删除包含子级的书签会先确认，F2/Delete/Enter 保持可用。

Ctrl+E 或“数据 → 导出带注释的 PDF”生成新 PDF，可选择文件名和位置，目标存在时确认覆盖。包含高亮、下划线、文本、手写、形状、直线和便签（含副文本）的外观；原 PDF 保持不变。

导出的批注外观可直接查看和打印；继续调整批注时请使用原 PDF 与 .pdfdata。原页面可搜索文字、内嵌目录和链接保留，用户书签仍在数据文件中。导出失败不会留下半成品覆盖有效目标；原 PDF、数据或目标在导出期间变化时会停止覆盖。

annotated-demo.pdf 为导出样例，原始样例为 navigation.pdf。
