# PDF 阅读器（里程碑 2）

## 运行

1. 解压 `PDFReader-M2.zip` 到一个文件夹。
2. 双击 `PDFReader.exe`，点击“打开 PDF”。也可以把 PDF 路径作为启动参数传给 EXE。
3. 页面会纵向连续排列并水平居中；滚动条和鼠标滚轮用于连续阅读。
4. 打开多个 PDF 会显示为标签页。每份 PDF 的页码、页内位置、缩放和标注分别保存。
5. 点击“区域高亮：拖拽框选”，在页面上拖动鼠标创建区域高亮。标注自动写到同目录独立 `.pdfdata` 文件。

源 PDF 以只读方式打开。`示例 PDF.pdf` 可用于快速试用；`.pdfdata` 文件可与对应 PDF 一起复制到其他电脑。

## 数据恢复

保存时会写入 `.tmp` 文件，并为旧数据保留 `.bak`。下次打开时发现较新的恢复文件或备份会询问是否恢复；恢复时会留下被选择文件的保护副本。

## 当前范围

此版本完成连续阅读、页面居中、多标签、进度持久化、SHA-256 版本识别和 sidecar 保存/恢复基础。当前可创建区域高亮。目录/用户书签、文本选择式高亮、下划线、文本批注、手写、形状、便签、跨窗口拖出标签、丰富的标注编辑和导出带注释 PDF 尚未实现。

本版本使用 Windows 自带 PDF 渲染 API。源码位于仓库 `src/` 目录。
