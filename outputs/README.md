# PDFReader M4.1

升级前先关闭旧版，解压后运行 PDFReader.exe，保留全部 DLL 与配置文件及已有 data 文件夹，需要 Windows 10/11 和 .NET Framework 4.8。请放在可写的文件夹中。

## 阅读与数据

右侧工具占阅读区高度 80%，8 组控件均匀分布，默认透明度 60%。目录只显示章节名称，缩略图单独显示页面预览。标签可点击 X 或双击关闭、拖动排序、拖出窗口独立阅读。

数据保存于 EXE 同级的 data 目录，按 PDF 内容哈希固定命名。再次打开相同内容时读取已有记录并恢复页码、页内位置和缩放。旧版放在 PDF 旁的 .pdfdata 会自动导入，旧文件保留，之后只更新 data 中的文件。内容被修改时会询问如何处理旧记录，不会覆盖原 PDF。

跨电脑迁移应复制整个 data 文件夹及 PDF，不能仅复制 PDF。不要用旧版阅读器读取新版 v5 数据。保存失败时修改保留在内存中，并显示错误；关闭前会重试保存。

## 注释

右侧直接显示选择、高亮、下划线、宋体 A 文本、手写、矩形、椭圆、直线 8 个图标，悬停查看名称和快捷键。高亮和下划线优先贴合文字区域，无可提取文字时按框选区域标注。

点击 A 后再点击页面即可直接输入中文、多行文本。拖动“文本批注”标题移动，右下角调整框大小。快捷面板提供 6 色圆点及色号、字号/线宽与透明度滑条，两侧加减按钮微调。选择已有注释也会显示快捷样式面板，F2 保留专业属性弹窗，支持自定义颜色和跨页移动。

停止输入 400ms 自动保存；Ctrl+S 立即保存，Ctrl+Enter/完成/页面空白处结束。Esc 放弃尚未提交的编辑；已自动保存的编辑可结束后 Ctrl+Z 撤销。清空文本删除批注，空框不会保存。切换标签、拖出窗口及关闭会提交待保存输入。原 PDF 始终不变。

Ctrl+Shift+A 选择，H 高亮，U 下划线，T 文本，P 手写，R 矩形，E 椭圆，L 直线（后七项同样按住 Ctrl+Shift）。Esc 取消当前操作。F1 查看所有阅读与书签快捷键。

扫描目录自动识别、OCR、便签和导出带注释 PDF 暂未实现。navigation.pdf 提供目录/链接/文字位置样例，continuous.pdf 提供连续阅读样例。
