# PDF 阅读器（里程碑 1）

这是第一条可运行的阅读器链路：打开 PDF、渲染页面、拖拽添加区域高亮、保存独立数据文件，并在重新打开时恢复高亮。

运行环境：Windows 10 或 Windows 11。

## 运行

1. 双击 `PDFReader.exe`，点击“打开 PDF”。也可以把 PDF 文件路径作为启动参数传给 EXE。
3. 点击“区域高亮：拖拽框选”，在页面上拖动鼠标添加高亮。
4. 高亮自动保存到 PDF 同目录的同名 `.pdfdata` 文件中，例如 `报告.pdf` 对应 `报告.pdfdata`。
5. 关闭并重新打开 PDF，已保存的高亮会恢复。

`示例 PDF.pdf` 可以用来快速试用。原始 PDF 以只读方式打开，程序只写入旁边的 `.pdfdata` 文件。

## 当前范围

本版本用于验证渲染、页面坐标和独立保存链路。高亮是矩形区域标注；多标签、文字选择式高亮、下划线、手写、形状、便签、书签和导出带注释 PDF 尚未实现。

程序使用 Windows 自带的 PDF 页面渲染 API，不需要安装第三方 PDF 组件。`PDFReaderApp.cs` 是对应源码。
